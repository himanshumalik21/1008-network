# Elite Web Development & UI/UX Standards Rule

Whenever working on UI components, layouts, pages, animations, or styling:
1. **Scrolltide**: Use velocity-aware scroll transformations, sticky stacking cards, kinetic scrubbers, and smooth parallax.
2. **Navbar Gallery**: Use floating glassmorphic islands, active tab sliding pills (`layoutId`), mega-menus with icons and descriptions, and mobile drawers with locked scroll and stagger transitions.
3. **Footer Design**: Implement structured multi-column sitemaps, system status indicators (pulsing operational badges), gradient dividers, newsletter captures, and ambient bottom watermarks.
4. **CTA Gallery**: Create Bento CTA containers with radial spotlights, dual-intent conversion buttons, and integrated social proof badges.
5. **Refero**: Adhere to an 8pt grid (`gap-2, 4, 6`, `p-6, 8, 10`), authentic domain-specific copy, nested border radius formula ($R_{inner} = R_{outer} - P$), and micro-badges.
6. **Superhero Hero**: Lead with an eyebrow status pill, commanding clamp-sized headline with gradient accents, concise 1-2 sentence subtitle, dual action triggers, and an interactive 3D/mockup hero showcase.
7. **3D Icons**: Employ glossy materials, brand rim lighting (Mint `#00D4B2`, Iris `#635BFF`, Navy `#0A2540`), sub-pixel floating levitation, and Retina 2.5x scaling.
8. **Framer Motion**: Prefer physics springs (`stiffness: 260, damping: 20`), orchestrated staggers, layout transitions, and micro-hover/tap states (`scale: 1.01`, `scale: 0.98`).
9. **UI/UX Pro Max**: Maintain WCAG AA/AAA contrast (>= 4.5:1), min 44x44px touch targets, zero CLS with fixed aspect ratios, visible focus-visible rings, and flawless horizontal overflow containment.
10. **21st.dev**: Leverage animated primitives like Border Beam, Shimmer Button, Number Ticker, Infinite Marquee, and Spotlight Cards.
11. **Get Layers**: Follow the 7-tier elevation architecture (Canvas `z-0` -> Ambient Glow `z-0` -> Content Canvas `z-10` -> Interactive Cards `z-10/20` -> Floating Accents `z-20` -> Sticky Nav `z-40/50` -> Overlays `z-60`).
